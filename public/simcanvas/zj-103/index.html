模型与洞察

光程差 = 2d + λ/2。当 2d + λ/2 = kλ 时形成暗环。环半径 rₖ = √(kλR)，因此越往外环间距越小——中心疏、边缘密。

教学视图：空气隙厚度 d = r²/(2R)，从中心向外递增。反射光光程差随厚度增大，形成周期性明暗交替。半波损失使中心为暗斑。
