教学要点

  • 时间常数 τ = RC 决定充电快慢：t = τ 时 U_C ≈ 63.2%·U₀（图中橙色虚线交点）；约 5τ 后基本充满。
  • 换路定则：电容电压 U_C 连续、不能跳变。任意时刻拨动开关，曲线都从当前 U_C 出发，无突变。
  • 充电：U_C 从 0 渐近趋于 U₀；电流从最大值 U₀/R 指数衰减到 0。
  • 放电：U_C 渐近趋于 0；由于回路串入了灯泡 R_L，τ′ = (R + R_L)C > RC，放电比充电更慢，电流方向与充电时相反。
  • 小灯泡亮度由放电电流驱动，随 U_C 衰减而逐渐变暗；增大 R 或 C 都会放慢整个过程。
