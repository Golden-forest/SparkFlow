🎯 平抛运动交互仿真

高处平台上的小球 A 以水平初速度 v₀ 抛出；同高度处对照球 B 由静止释放 —— 观察两方向运动的独立性与等时性（忽略空气阻力）

📚 教学要点

  1. 水平方向 — 匀速直线运动：水平方向不受力，vx = v₀ 保持不变，x = v₀t（频闪点水平间距始终相等）。
  2. 竖直方向 — 自由落体：vy = g·t，y = ½gt²，与对照球 B 的下落完全相同。
  3. 独立性与等时性：两方向运动互不影响、同时进行。任意时刻 A、B 两球等高（见白色连线），同时落地；T = √(2h/g) 只由 h、g 决定，与 v₀ 无关。
  4. 射程：R = v₀·√(2h/g)，与 v₀ 成正比。
💡 动手试：① 只增大 v₀ → 落地时间不变、射程变大；② 只增大 h → 时间与射程都变大；③ 切换 g = 9.8 与 10，比较 T 与 R。
快捷键：空格 = 播放/暂停 · → = 单步 · R = 重置 ｜ 理想模型：忽略空气阻力
