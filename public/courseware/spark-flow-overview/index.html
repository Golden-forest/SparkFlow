Spark Flow · 高中物理虚拟实验平台

15 个可动手调参的 3D 物理实验，覆盖 7 个领域

Spark Flow2026-08-06

第 01 节

这是什么

Spark Flow 是一个跑在浏览器里的物理实验仿真平台。它把课本里那些"想象一下"的物理场景——α 粒子轰击金箔、电子在能级间跳跃、卫星绕地球转、两辆车撞在一起——做成了 15 个可以动手玩的实验。

每个实验都是真仿真：拖动滑块改参数，物理引擎实时算，3D 场景实时变，数据图表实时画。不是 PPT，不是视频，是真能调的实验。

第 02 节

平台首页一览

点击图片即可打开 Spark Flow 在线平台。首页把 15 个实验铺成卡片墙，按领域归类，鼠标悬停即可看到实验关键词。顶部三个 Tab——实验、课件、图片——把"动手做"、"看讲义"、"看结果"三条路径分得很清楚，学生不需要菜单翻找。

单摆、运动与碰撞、平抛、圆周运动、斜面摩擦、弹簧振子、动量碰撞
04

同步加速器与洛伦兹力
05
光学

06

07
电化学
原电池粒子流与实时电化学计算
第 04 节

双视图：宏观装置 ⇄ 微观机制

卢瑟福散射

  • 宏观视图：α 源、金箔、环形探测屏与散射统计
  • 微观视图：近距离观察库仑偏转轨迹

同步加速器

  • 宏观视图：整个加速器环全景
  • 微观视图：单个粒子在 E/B 场中的 4 种机制——RF 加速、磁弯曲、同步轨道、碰撞点
第 05 节

同步加速器：宏观全景

环形束流管道是骨架，RF 加速腔负责每圈给粒子补能量，弯曲磁铁把粒子轨迹压成圆弧，碰撞点把两束粒子导向同一位置。从全景就能看清"加速—弯转—碰撞"三件事在哪里发生。

第 06 节

同步加速器：粒子碰撞瞬间

微观视图把镜头推到碰撞点：两束带电粒子相向飞来，磁场把它们会聚到微米级斑点。交汇瞬间能量释放以辐射光晕呈现，次级粒子沿不同方向散射——这正是高能物理实验要采集的信号。

第 07 节

声明式控制面板：写配置，不写 UI

实验开发的核心是 ControlSchema 和 MonitorSchema——你声明"有哪些参数可调、有哪些量要监控"，框架自动渲染滑块、开关、按钮和实时折线图。加一个新参数只需加一行配置，不用碰 UI 代码。

每个实验运行时，选中的物理量（位移、速度、能量、力）会被自动采集并以实时折线图呈现（基于 recharts）。监控哪些量也是声明式配置的，最多保留最近 100 个数据点。

典型控件类型覆盖：连续滑块（力、质量、角度）、开关（显示轨迹、暂停）、按钮（发射、重置）、下拉选择（粒子种类）。参数变化即时反映到仿真和数据曲线上。

第 08 节

技术栈

  • 框架：React 19 + TypeScript，UI 与类型安全
  • 3D 渲染：Three.js + React Three Fiber + drei，声明式写 3D 场景
  • 2D 渲染：原生 Canvas + requestAnimationFrame
  • 物理引擎：自实现物理计算 + cannon-es，每实验独立 *Physics.ts
  • 动画：GSAP + @react-spring/three
  • 状态：Zustand，单一 simulationStore 管全部仿真状态
  • 构建：Vite 7，极速 HMR；E2E 测试用 Playwright
第 09 节

插件式实验架构

所有实验遵循 IExperiment 接口（3D）或 IExperiment2D 接口（2D），通过注册中心统一管理。新增实验只需：在 src/experiments/{category}/{name}/ 下创建实验类，实现 init / update / getControlSchema / getMonitorSchema，然后在注册中心与路由登记。

状态机驱动仿真生命周期：Idle → Start → Running ⇄ Paused → Reset → Idle，所有组件订阅同一状态源，保证 UI 与仿真同步。视图根据元数据 renderMode: '2d' | '3d' 自动选择渲染管线。

实验目录约定

  • index.ts 导出实验元数据与类引用
  • *Physics.ts 实现该实验的物理计算
  • components/ 存放场景组件、材质、几何体
  • constants.ts 存放默认参数与物理常数
第 10 节

Vite 自定义插件

资源清单插件——开发和构建时自动扫描 public/courseware/ 与 public/images/，生成 resource-manifest.json，首页据此渲染课件与图片卡片。文件变化时 80ms 防抖重新生成。

课件路由中间件——在 Vite 的 SPA fallback 之前拦截 /courseware/{name} 请求，直接返回子目录下的 index.html。这解决了 SPA 路由会"吃掉"课件 HTML 的问题。

第 11 节

快速开始

01
npm install 安装依赖
02
npm run dev 启动开发服务器（默认 5173 端口）
03
npm run build 构建生产版本
04
npm run test:e2e 运行 Playwright 冒烟测试
05
npm run import:courseware path/to/lesson.html 导入 HTML 课件
06
环境要求
Node.js 18+，支持 WebGL 2.0 的现代浏览器
