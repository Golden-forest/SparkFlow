# 天体运动实验开发计划

## 1. 项目架构分析

### 核心架构
- **基于React + TypeScript + Three.js**的实验模拟平台
- **面向对象设计**：每个实验都是独立类，继承自`ExperimentBase`
- **实验注册机制**：通过`@registerExperiment`装饰器自动注册
- **清晰的生命周期**：`init` → `start` → `update` → `pause` → `resume` → `reset` → `dispose`
- **组件化设计**：UI组件与实验逻辑分离

### 可复用组件
- `SceneContainer`：3D场景容器
- `ControlPanel`：参数控制面板
- `PlaybackControls`：播放控制
- `SideToolbar/AbstractSideToolbar`：侧边工具栏
- `DataDisplay`：实时数据显示

## 2. 实验设计

### 实验概述
- **名称**：天体运动模拟
- **包含两个视图**：
  - 银河系视图：展示太阳系行星运动
  - 地球卫星视图：展示地球周围卫星运动
- **跳转机制**：类似氢原子实验的抽象视图跳转

### 目录结构
```
src/experiments/
└── celestial/
    ├── solar-system/
    │   ├── SolarSystem.ts        # 主实验类
    │   ├── CelestialPhysics.ts    # 天体物理计算
    │   ├── Planet.ts              # 行星类
    │   ├── Satellite.ts           # 卫星类
    │   └── index.ts               # 导出文件
    └── index.ts                   # 实验注册
```

## 3. 实现步骤

### 步骤1：创建实验基础结构
1. 创建`celestial/solar-system`目录
2. 实现`CelestialPhysics.ts`：万有引力计算、轨道运动模拟、行星参数定义
3. 实现`Planet.ts`和`Satellite.ts`：3D模型创建、轨道动画、状态管理

### 步骤2：实现主实验类
1. 创建`SolarSystem.ts`，继承自`ExperimentBase`
2. 实现`metadata`和`config`属性
3. 实现`setupScene()`：创建银河系背景、太阳和行星、设置相机位置
4. 实现`update()`：更新行星位置、检测交互事件、管理跳转逻辑
5. 实现`onStart()`、`onReset()`等生命周期方法

### 步骤3：添加跳转机制
1. 在`App.tsx`中添加路由：
   - `/experiment/solar-system`：主视图
   - `/experiment/solar-system/satellite`：卫星视图
2. 在工具栏中添加跳转按钮

### 步骤4：注册实验
1. 在`celestial/index.ts`中注册实验
2. 确保实验能在首页被发现

## 4. 关键技术点

### 物理模拟
- 采用数值积分（如Verlet方法）模拟轨道运动
- 实现万有引力定律：F = G * m1 * m2 / r²
- 考虑参考系转换：从银河系到地球卫星视图

### 3D可视化
- 使用Three.js创建行星模型和卫星模型
- 实现轨道线和运动轨迹
- 添加缩放和平移功能，方便观察

### 交互设计
- 点击行星可跳转到卫星视图
- 提供参数调节：时间流速、视角切换、显示/隐藏轨道

## 5. 预期效果

- **银河系视图**：展示太阳系行星围绕太阳的运动
- **地球卫星视图**：展示地球周围卫星的运动，包括同步卫星、极地卫星等
- **平滑跳转**：在两个视图间无缝切换
- **参数可调**：用户可调节时间流速、视角等参数
- **数据显示**：实时显示行星/卫星的位置、速度、加速度等数据

## 6. 与现有实验的一致性

- 遵循相同的类结构和生命周期
- 使用相同的UI组件和样式
- 采用相同的注册机制和路由模式
- 保持代码风格和命名规范一致
