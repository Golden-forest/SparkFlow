# Multi-body mechanical energy teaching animations

Nine offline pages in `public/simcanvas/energy-*/`, generated by
`scripts/simcanvas-multi-body/build.cjs`. `meta.json` provides Chinese/English
names for the existing SimCanvas gallery. No framework or CDN runs inside these
pages; source templates and the shared physics kernel remain versioned.

## Scope and layout

Confirmed on 2026-10-13: main animation ~70%, energy evidence alongside, bottom
playback/display controls. **No insight region**, explicitly requested by the
user. Equation text is hidden initially. A/B colors agree across bodies,
velocity arrows, individual mechanical energy changes and equations. Scope
buttons select A, B or A+B+Earth for energy bars. Chart always labels all three.

These are representative textbook structures from the left-hand nine diagrams,
not a numerical reproduction of the cropped right-hand Example 4. Finite pulley
pictures are schematic; the variable-angle cord case uses a point guide. The
cylinder is a fixed frictionless cord guide, A translating horizontally and B
vertically; no cylinder rotation or ball rolling energy is included.

## Physics contract

- SI; x right, y up; `g = 9.8 m/s²`; A/B are point masses. Energy displays show
  **changes since release**, gravitational references at the initial positions.
- Light inextensible cords, massless rigid rods, ideal fixed guides/pivots,
  frictionless slider rails. Support reactions do zero total work. Rod forces
  may do work on individual masses; their internal powers cancel in the system.
- One generalized coordinate q and speed u determine both bodies, velocities,
  accelerations, energy and diagrams. From rest, render one first-motion segment
  ending before collision, ground contact, cable slack or a rod/rail singularity.
  The last displayed velocity is generally **nonzero**: stopping playback is not
  presented as a physical stop. No collision/rebound/slack continuation is claimed.
- Four equal-speed systems: cord travel s; constant acceleration. The incline
  is 30°. Three angular systems: clockwise q, with vA/rA = vB/rB = u.
- Slanted cord: A=(0,H-z), B=(D,H-b0-l0+l), l=sqrt(D²+z²).
  `|vA| z/l = |vB|`; cord tension is checked nonnegative throughout.
- Perpendicular sliders: A=(0,L cos q), B=(L sin q,0), fixed rod length L;
  `|vA| cos q = |vB| sin q`. Avoid q=0 and q=pi/2 boundary geometries.
- General dynamics: `M qddot + M' u²/2 + U' = Fq`,
  `M=sum(m |dr/dq|²)`, `U=sum(mgy)`. Geometry derivatives are exact.
- Fixed 1 ms RK4 step, final travel located by 40-step bisection. Sampling advances
  the remaining fraction of a step from a saved state; no position/energy
  interpolation and no second physics clock. Frame gaps are clamped to 50 ms;
  playback rates map wall time to physical time without changing the solver step.
- Only cart has rough/smooth switch; rough `mu_s=mu_k=0.25`, with default masses
  ensuring first downward motion. Heat Q=mu*mA*g*s. Changing friction resets the
  run, rebuilds the physical trajectory, and updates every view. Reset preserves
  friction/rate/display choices and clears dynamic state/history.
- Mechanical energy: delta K + delta U = 0 (ideal), or = -Q (rough cart).
  Arrow lengths share the same m/s scale within a page; diagram elements are
  enlarged, not literal apparatus dimensions. No decorative physical motion.

## Exact commands

```bash
node scripts/simcanvas-multi-body/build.cjs
node scripts/simcanvas-multi-body/check.cjs
node scripts/simcanvas-multi-body/check-browser.cjs
node --import tsx scripts/resource-manifest.ts
```

Browser checks use installed Playwright Chromium; install via the repository's
`npm run test:e2e:install` if absent. Screenshots default to
`/private/tmp/multi-body-energy-check`; override `MULTI_BODY_SCREENSHOTS`.
The aggregate check returns nonzero on required failure. It runs the skill's
standard validator and permits only the single confirmed missing-insight
finding; every other validator failure remains blocking. Set
`SIMCANVAS_VALIDATOR` if the skill is installed elsewhere.

## Evidence and limits

- Model: 184 checks, including initial/final states, conservation (1e-6 J),
  speed/length constraints, analytic constant-acceleration solutions, angular
  energy solution, equal-mass and reversed-mass Atwood cases, tension sign,
  frictional thermal energy, derivatives and step-halving (1e-7).
- Independent oracle: Python standard-library energy quadrature, 18 mid/end
  snapshots across all nine; time tolerance 2e-6 s, generalized-speed tolerance
  1e-7 SI. Does not import the JavaScript force solver.
- Browser: all nine, 1440x900 / 390x844 / 844x390, playback/pause/resume/reset,
  scrubbing, scope selection, display switches, equations, cart friction,
  object positions/readouts versus authoritative state, page errors and layout.
- Presentation review: apparatus silhouettes, angle marks, shared arrow scale,
  visible initial positions, individual energy transfer and constant system line.
- Delivery uses a separate release directory based on the current production
  source plus these static pages, preserving unrelated dirty workspace changes.
  Existing shared access-code protection is preserved; authenticated online UI
  verification needs the user's existing authorized session.
