## 项目目标

把整个项目（高中物理仿真实验平台 Spark Flow）汉化，加语言切换按钮，实现中英双语可切换。

## 关键决策（用户已确认）

1. **方案**：中英双语可切换（A 方案），不是纯中文、不是中文+英文 fallback
2. **CLAUDE.md 规范**：从"必须英文"改为"必须走 i18n"（A 选项）
3. **i18n 库**：react-i18next + i18next（A 选项）
4. **翻译键组织**：按命名空间拆分（B 选项）— common.json + home.json + experiments/{id}.json
5. **语言切换按钮**：仅首页显示（B 选项），纯文字"中 / EN"双标签高亮当前（不要国旗图标）
6. **默认语言**：中文（A 选项），localStorage('sparkflow.lang') 持久化
7. **范围**：主路径全覆盖，3D TextSprite 延后（B 选项）
8. **metadata 策略**：metadata.name/description/keywords 保持英文不变（方式甲）
9. **getDisplayData() 策略**：返回 labelKey 可选字段，UI 层调 t()（方式甲）
10. **DisplayValue 接口**：加 labelKey? 字段，不替换 label（渐进式迁移，fallback 到英文 label）
11. **不写新单元测试**，靠浏览器端到端验证

## 关键技术约束

- **同步初始化**：i18next 用 bundled JSON import，不用 http-backend、不用 Suspense、不用 lazy load
- **不引入 i18next-browser-languageDetector**：手动读 localStorage
- **localStorage key**：`sparkflow.lang`，值为 `'zh-CN'` 或 `'en-US'`
- **状态保留**：i18next.changeLanguage 只触发重渲染，zustand store 不受影响（实验运行状态保留）
- **3D TextSprite 不翻译**（同步辐射等），留作后续 PR
- **物理符号/单位/元素符号/数学公式不翻译**（R、C、U₀、kΩ、μF、Zn、Cu 等）

## 改造分批

- **批 1**：基础设施 + 首页（i18n/config、LanguageSwitcher、36 个 JSON、main.tsx、Home.tsx）
- **批 2**：通用组件 + 16 个实验层（PlaybackControls、DataDisplay、ControlPanel、氢原子 3 个工具栏、力学组件、各实验 getDisplayData 加 labelKey、2D 视图 SVG text）
- **批 3（本次不做）**：3D TextSprite 翻译

## 接口变更

`DisplayValue`（在 `src/experiments/base/` 定义处）：
```ts
interface DisplayValue {
  label: string;        // 保留（fallback）
  labelKey?: string;    // 新增：i18n key
  value: number | string;
  unit?: string;
  precision?: number;
}
```

DataDisplay.tsx 改造：
```tsx
<span>{item.labelKey ? t(item.labelKey) : item.label}</span>
```

## LanguageSwitcher 设计

位置：Home.tsx `<header>` 右上角（绝对定位），**仅首页显示**
样式：胶囊状，两个按钮 "中" 和 "EN"，当前语言高亮（渐变 cyan-600 → sky-500）
点击：调用 `i18n.changeLanguage('zh-CN' | 'en-US')`
